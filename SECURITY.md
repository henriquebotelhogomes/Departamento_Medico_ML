## Versões com Suporte

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportando uma Vulnerabilidade

A segurança dos dados e modelos médicos no projeto RadioAI é levada muito a sério.
Se você identificar uma vulnerabilidade de segurança, por favor **NÃO** abra uma issue pública.

Em vez disso:
1. Abra um [Security Advisory privado no GitHub](https://github.com/henriquebotelhogomes/Departamento_Medico_ML/security/advisories/new).
2. Forneça uma descrição detalhada do problema, passos para reproduzir, impacto potencial e qualquer prova de conceito (PoC).
3. Responderemos o mais breve possível com a avaliação e o cronograma de correção.
